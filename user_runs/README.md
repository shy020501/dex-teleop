# dex-teleop - User Runs

This directory contains local, user-specific configurations and runtime logs
for Bench2Dex teleoperation. Its contents are excluded from Git except for this guide.

## Directory Structure
- `<user>/`: Personal teleoperation configuration and logs. Choose a local directory name.

## Notes
- Shared Bench2Dex source code and default configurations are maintained separately.
- Each user should keep personal configurations and logs in their own directory.
- Do not modify or interrupt other users' running sessions.
